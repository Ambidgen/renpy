All ten location backgrounds were generated for this project with an AI
image model. They are original to The Grass and are released under the same
licence as the rest of this prototype. The full-size originals are kept in
`the-grass-art/raw/`; the game uses 720x1280 JPEG derivatives.

## Character sprites

The cast is composited from the **Universal LPC Spritesheet Character
Generator** (the Liberated Pixel Cup sprite bank), then recoloured along the
project's own palette ramps by `the-grass-art/tools/build_assets.py`.

> LPC assets are licensed **CC-BY-SA 3.0** and **GPL 3.0**. Attribution for
> the individual layers follows. If you redistribute this game, keep this
> file with it.

  (wulax), bluecarrot16, BenCreating, Eliza Wyatt (ElizaWy), Nila122,
  David Conway Jr. (JaidynReiman), Marcel van Dorst (madmarcel)
